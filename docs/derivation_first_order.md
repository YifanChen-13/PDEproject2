# B: 一阶 Neumann / Robin 边界闭合

## 范围与公式

实现仓库 Direction 2 的 B 分工：单位正方形，`-Delta u=f`，右侧外法向
`n=(1,0)`。只处理 `x=1, 0<y<1`；四个角点沿用 A 的 Dirichlet 消元。
本模块不处理 Problem Pack Direction 1 的圆盘问题。

令 `h=1/N`。在 `(1,y_j)` 用后向差分近似外法向导数：

$$u_x(1,y_j)\approx (U_{N,j}-U_{N-1,j})/h.$$

Neumann 条件得到

$$-h^{-1}U_{N-1,j}+h^{-1}U_{N,j}=q(y_j).$$

Robin 条件得到

$$-h^{-1}U_{N-1,j}+(h^{-1}+\beta)U_{N,j}=r(y_j),\qquad\beta=2.$$

其中 `q=exp(1+y)`、`r=3 exp(1+y)`。没有改变法向符号，也没有乘负号。
这条导数方程替代边界处的 PDE 方程；不叠加五点行、不引入 ghost 点，
也不再把 `f` 加到该行。`N>=2` 时向内邻点 `(N-1,j)` 总是未知量，
所以这一阶边界行没有额外的 Dirichlet 移项。上下相邻节点不出现在该行中。

## 手算小网格

`N=2` 时未知量 `(1/2,1/2),(1,1/2)`，边界行分别为 `[-2,2]` 与
`[-2,4]`，右端分别为 `exp(1.5)` 与 `3 exp(1.5)`。

`N=4` 时边界行编号为 `3,7,11`，各自仅在列 `(2,3)`、`(6,7)`、
`(10,11)` 有非零项。Neumann 系数为 `(-4,4)`，Robin 为 `(-4,6)`；
相应右端按 `y=1/4,1/2,3/4` 计算。内部行保持 A 的系数和右端不变。

## 一致性与误差来源

Taylor 展开给出

$$\frac{u(1,y)-u(1-h,y)}{h}=u_x(1,y)-\frac h2u_{xx}(1,y)+O(h^2).$$

因此边界局部缺陷是一阶。代入 `u*=exp(x+y)`，两种条件的未缩放边界缺陷相同：

$$\tau_j=e^{1+y_j}\left[\frac{1-e^{-h}}h-1\right]
=-\frac h2e^{1+y_j}+O(h^2).$$

Robin 的精确 `beta*u` 项和边界数据中的对应部分抵消。
此缺陷是精确解样本对离散方程的不满足量，与数值解误差、求解残差不同。
内部五点行仍是二阶，但一阶边界可能限制全局误差收敛率，需要实际测量。
与 C 的方法比较时还应说明：ghost 方法在边界施加消元后的 PDE，
二者的方程结构也不同，不能把全部差异只归因于导数近似阶数。

边界行尺度为 `h^-1`，内部 PDE 行尺度为 `h^-2`；矩阵一般非对称。
诊断使用原矩阵上的分量缩放后向残差

$$\eta=\max_k\frac{|(Au_h-b)_k|}{(|A||u_h|+|b|)_k}.$$

小残差本身不是前向误差界；条件数估计或独立紧容差求解的正式验证留给 E。

## 接口、验证与交接

`apply_first_order(A,b,problem,grid)` 接收 A 的 LIL 矩阵和浮点右端，原位
替换开放右边界行并返回同一对象。整行替换保证重复调用不累加贡献，其他行不变。
问题与网格的 N 不同时，在修改输入前报错。

运行 `python -m pytest -q -p no:cacheprovider`。新增测试覆盖小网格手算、
内部行与角点保留、幂等性、指数制造解缺陷、线性函数的精确导数，及两种条件下
SciPy `spsolve` 的小规模集成检查。E 的 `solver.py` 接口不在 B 中实现。

验证结果及尚待人审事项见 [handoff_B.md](handoff_B.md)。
