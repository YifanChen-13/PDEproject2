# A 阶段：计算前记录

记录日期：2026-11-03。以下预期在首次运行本仓库检查前写下。

本阶段只检查网格与离散矩阵，不求解混合边界线性系统。右边界行尚未填入，因此基础矩阵应当是奇异的，不能直接送入求解器。

| 检查 | 事先预期 | 理由 |
|---|---|---|
| 未知量数 | `N * (N - 1)` | 保留 `1 <= i <= N, 1 <= j <= N-1`；三条 Dirichlet 边已消元 |
| 内部 PDE 行数 | `(N - 1)**2` | 仅在 `1 <= i,j <= N-1` 施加内部五点差分 |
| 预留右边界行数 | `N - 1` | 两个右角点属于 Dirichlet 边，不属于开放右边界 |
| 系数符号 | 对角元 `4/h**2`，未知邻点系数 `-1/h**2` | 使用 `-Delta u = f` |
| 已知边界项 | 以 `+g/h**2` 加入右端 | 从左侧移项，不能沿用负号 |
| 右边界行 | 矩阵行和右端都为零 | 留给 B、C 分别填入，不能提前混入某一种闭合 |
| 精确解代入内部行的缺陷 | 加密后约缩小至四分之一 | 五点差分作用于 `exp(x+y)` 的内部截断误差为二阶；这不是解误差 |

解析核对：`u_xx = u_yy = exp(x+y)`，因此 `f = -2 exp(x+y)`。在右边界，外法向是 `(1, 0)`，故 `q = exp(1+y) > 0`；`beta=2` 时 `r=3 exp(1+y)`。
